================================================================================
Sentiment Analysis MLOps & Production Azure Deployment Workflow
================================================================================

------------------------- 1. Local Environment Setup -------------------------

1. Clone repository:
   git clone https://github.com/rohitkr8527/sentiment-analysis.git
   cd sentiment-analysis

2. Create and activate Python virtual environment:
   # Windows:
   python -m venv .venv
   .\.venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate

3. Install project dependencies:
   python -m pip install --upgrade pip
   pip install -r requirements.txt

4. Configure local environment variables:
   cp .env.example .env

------------------------- 2. MLOps Data & Pipeline (DVC) -------------------------

5. Ingest and split dataset:
   python -m src.data.data_ingestion

6. Preprocess text data (URL removal, punctuation, stopwords, lemmatization):
   python -m src.data.data_preprocessing

7. Run feature engineering (TF-IDF vectorizer + sparse matrices):
   python -m src.features.feature_engineering

8. Train Logistic Regression model:
   python -m src.model.model_building

9. Evaluate model performance and metrics:
   python -m src.model.model_evaluation

10. (Optional) Run entire DVC pipeline:
    dvc repro
    dvc status

------------------------- 3. Automated Testing -------------------------

11. Run pytest test suite:
    pytest tests/ -v

12. Run with code coverage:
    pytest tests/ -v --cov=fastapi_app --cov=src

------------------------- 4. Running Application Locally -------------------------

13. Start FastAPI application:
    uvicorn fastapi_app.app:app --host 0.0.0.0 --port 8000 --reload

14. Access endpoints:
    - Web UI: http://localhost:8000/
    - Interactive Swagger Docs: http://localhost:8000/docs
    - Health Check: http://localhost:8000/health
    - Prometheus Metrics: http://localhost:8000/metrics

15. Run via Docker Compose:
    docker compose up --build -d
    docker compose ps
    docker compose logs -f

------------------------- 5. Azure Production Cloud Deployment -------------------------

16. Authenticate with Azure CLI:
    az login
    az account set --subscription "<SUBSCRIPTION_ID>"

17. Create Resource Group:
    az group create --name rg-sentiment-prod --location eastus

18. Create Azure Container Registry (ACR):
    az acr create --resource-group rg-sentiment-prod --name <UNIQUE_ACR_NAME> --sku Basic --admin-enabled true

19. Build & Push Docker image using ACR Cloud Build:
    az acr build --registry <UNIQUE_ACR_NAME> --image sentiment-analysis-api:latest .

20. Create App Service Plan (Linux Basic B1):
    az appservice plan create --name plan-sentiment-prod --resource-group rg-sentiment-prod --sku B1 --is-linux

21. Create Azure Web App for Containers:
    az webapp create \
      --resource-group rg-sentiment-prod \
      --plan plan-sentiment-prod \
      --name <UNIQUE_APP_NAME> \
      --deployment-container-image-name "<UNIQUE_ACR_NAME>.azurecr.io/sentiment-analysis-api:latest"

22. Configure App Settings and Health Probes:
    az webapp config appsettings set \
      --name <UNIQUE_APP_NAME> \
      --resource-group rg-sentiment-prod \
      --settings WEBSITES_PORT=8000 PORT=8000 ENVIRONMENT=production LOG_LEVEL=INFO

    az webapp config set \
      --name <UNIQUE_APP_NAME> \
      --resource-group rg-sentiment-prod \
      --generic-configurations '{"healthCheckPath": "/health"}'

23. Verify Deployment:
    curl https://<UNIQUE_APP_NAME>.azurewebsites.net/health

------------------------- 6. CI/CD Setup with GitHub Actions -------------------------

24. Generate Azure Service Principal credentials:
    az ad sp create-for-rbac \
      --name "sp-sentiment-github" \
      --role contributor \
      --scopes /subscriptions/<SUBSCRIPTION_ID>/resourceGroups/rg-sentiment-prod \
      --sdk-auth

25. Configure GitHub Repository Secrets:
    - AZURE_CREDENTIALS: JSON output from step 24
    - AZURE_ACR_NAME: <UNIQUE_ACR_NAME>
    - AZURE_APP_NAME: <UNIQUE_APP_NAME>
    - AZURE_APP_URL: https://<UNIQUE_APP_NAME>.azurewebsites.net
    - Optional: DAGSHUB_TOKEN, AZURE_STORAGE_CONNECTION_STRING

26. On every push to main:
    - CI runs tests, linting, and Docker container verification
    - CD builds and pushes container to ACR, updates Azure App Service with zero downtime
